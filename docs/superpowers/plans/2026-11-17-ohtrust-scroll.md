# LikeWater 滾動敘事延伸

使用者希望在既有第 2 款居家視覺中增加畫面與滾動效果；保留本機預覽，不部署。

延續原版字體、暖白、木質與森林綠，新增三場景敘事與一幅通風居家全景。桌面左側文字逐段滾入、右側照片停留與淡換，附場景進度與跳至產品細節的連結。手機、矮螢幕與減少動態模式改為三張直式圖文，不強制捲動或隱藏說明。產品細節畫面加大，六份報告與原 FAQ、證據限制完整保留。

實作順序：
1. 保存原畫面與元件；依選定第 2 張及使用者瓶身照片生成接觸面、外出籠、通風居家三張獨立情境圖，輸出響應式 WebP。
2. 在 OHTrust.vue 加入三場景、固定照片舞台、自然捲動進度與結尾全景，所有事件與畫面更新在離頁清除。
3. 驗證三個場景依捲動切換、反向捲動、錨點、窄版和低動態閱讀；對照原視覺並修正；執行 build 與報告內容保留檢查。
4. 更新 design-qa.md，開啟本機預覽供使用者檢視。

驗收：增加實際圖像內容；無橫向溢出；文字不依賴動畫才可讀；沒有自動輪播或捲動攔截；報告資料不改寫；不提交、推送或部署。
