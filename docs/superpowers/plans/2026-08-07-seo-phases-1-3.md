# SEO Phases 1-3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Improve technical SEO, static first-response content, and verifiable article trust signals without migrating away from Vue 3 and Vite.

**Architecture:** Keep `src/seo.js` as the runtime metadata source and the existing static generator as the deployment path. Add build-time extraction of meaningful text from the six bespoke Vue article components, generate the public and deployment sitemap from the same route inventory, and keep reviewer/source/link facts in existing article data modules.

**Tech Stack:** Vue 3, Vue Router, Vite, Node.js test runner, Vue compiler SFC/DOM packages.

## Global Constraints

- Do not invent medical claims, reviewer credentials, publication dates, sources, prices, or reviews.
- Do not migrate to Nuxt or redesign the existing pages.
- Keep current metadata, canonical URLs, redirects, and schemas unless a direct conflict is identified.
- Use full static HTML for important content while retaining the existing Vue client experience.
