# 第二輪搜尋可信度優化

使用者指示「接著給他再優化」，延續已部署的 SEO/GEO 方向及部署授權。這一輪處理實際資料缺口，採用共用資料來源；不新增外部帳號或 AI 專用端點。

- 初始 HTML 的機構資料缺少門診時間，而載入後資料有時間。將機構 graph 抽成共用 builder，首頁可見七天班表也使用同一週門診資料，保留「實際看診依當月班表」提醒。
- 首頁的資訊整理責任歸於專心動物醫院，在頁尾以連到醫院介紹的機構署名呈現；WebPage.author 使用同一機構。這是首頁資訊整理，不是指定某位醫師審閱所有衛教。
- 既有文章作者仍以原資料為準：有原作者則連到對應醫師 Person ID，無作者則維持機構整理；不把審閱者轉成作者。只有已存在於 doctors 清單的個人資料能關聯 worksFor。
- Atom 每篇列原作者與介紹網址，RSS 使用 dc:creator，避免使用需要 email 的 RSS author 欄位。原發布日／更新日與全文資料不變。
- 保留 44 篇清單、原圖、臨床正文、8 位獸醫師、小寵物及電話／LINE 流程。

驗收：完整 verify、實際 XML 解析、首頁與代表文章初始／載入後資料一致、手機及小寵物檢查；獨立審查通過後備份並部署，核對全部 44 篇。GeoReady 若回傳舊快取，明確區分，不保證分數上升。
