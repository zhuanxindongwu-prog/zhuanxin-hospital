- 保留原始臨床正文、圖片、網址、8 位獸醫師與小寵物互動；沿用既有電話／LINE 聯繫流程。
- 首頁唯一 H1 為「專心動物醫院」，標語成為相鄰段落，維持原本字級與間距。

- sameAs 僅加入已核對的既有 Facebook、LINE 與維基百科身分網址；不建立或修改外部資料、不連到一般地圖搜尋作為身分證明。

- 文章與首頁可發現訂閱連結；靜態 HTML 與載入後 head 一致；私有 noindex 路由不增加訂閱宣告。
- 不為得分增加假數字、假審閱、假搜尋或預約功能，也不增建 ai.txt 或 AI JSON。
