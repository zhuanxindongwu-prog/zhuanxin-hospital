# 第一批分頁改版：專科服務與疾病指南

日期：2026-10-03

狀態：第一批範圍已確認；本份書面規格待使用者審閱。尚未開始產品程式修改、推送或部署。

## 1. 目的與已確認原則

讓訪客從新版首頁進入其他頁面時，感受到同一家醫院的視覺與導覽體驗。延續已核准首頁的暖白、森林綠、宋體標題、細線與留白，依內容用途調整閱讀節奏。

使用者已確認先做共用導覽、頁尾、三個專科服務頁與兩個疾病指南，完成後提供本機預覽，不部署。後續才處理獸醫師／班表、文章與產品等頁面的內文版型。

必須保留：

- 現有網址、醫療文字、完整標題、FAQ、參考來源與 SEO 資料。
- 使用者提供的照片、現有插畫、肖像與圖說，不生成或替換圖片。
- 首頁八位獸醫師與小寵物彈出效果。
- 電話、LINE、地圖、班表及導覽的既有可用性。
- 工作目錄內無關的 README 修改與尚未追蹤圖片。

## 3. 視覺標準

以現有 `src/components/homepage/homepage.css` 為設計依據：

- 背景暖白 `#f7f6f0`；主要文字／按鈕森林綠 `#233f35`。
- 次要文字 `#5f6c61`；分隔線 `#d5dacd`；分區可使用淺鼠尾草綠 `#e9ece2`。
- 標題沿用 Songti TC／Noto Serif TC／PMingLiU；內文沿用 PingFang TC／Noto Sans TC／Microsoft JhengHei。
- 桌面容器最大 1280px，左右留白 56px；平板 40px；手機 20px。
- H1 桌面約 48–64px、手機 32–38px，依長標題自然換行；不用截斷、省略號或強制不換行。
- 正文 16–18px、約 1.8 倍行高；主要閱讀欄寬控制在約 680–760px，避免長篇文字橫跨整個螢幕。
- 按鈕微圓角、細線、清楚對比；取消本批頁面的大面積漸層、玻璃效果與厚重陰影。
- 不增加視差、捲動綁定動畫、自動輪播或動畫套件。

UI UX Pro Max 的編輯式網格、標題層級、適當行寬與鍵盤操作建議用於本規格；其通用醫療配色及英文配字不取代已確認的中文首頁設計。Vue 樣式搜尋沒有精準資料庫匹配，實作邊界依現有專案的 scoped 樣式與元件結構決定，不因此新增套件或狀態管理。

## 4. 共用導覽與頁尾

### 導覽

採用暖白底、森林綠字、細底線與首頁同款中文／英文品牌排版。維持既有主要導覽目的地，保留產品入口，新增清楚可見的「查看門診」入口。介面中醫師團隊標示統一為「獸醫師團隊」。

桌面橫向排列；空間不足時改用手機選單，不以縮小字級塞入。維持固定在頂部的導覽方式，控制實際高度不超過既有 96px 錨點偏移；內容預留高度，避免標題被遮住。

手機選單使用原生按鈕，具可辨識名稱、`aria-expanded` 與 `aria-controls`。按 Escape 關閉並將焦點回到開關；點選連結或換頁後關閉。選單可在螢幕內捲動，正常捲動選單不應導致它突然關閉。不使用對話框角色，也不把焦點鎖在非模態導覽內。

### 頁尾

以淺鼠尾草綠的聯絡區與暖白品牌收尾延續首頁。既有地址、營業時間、電話、LINE QR Code、地圖與快速連結完整保留；緊急就醫提醒保留且清楚可讀。

手機底部電話／LINE／導航入口維持三個，不增加重複工具列。使用森林綠單色設計，保留安全區與底部空間，不遮住內容或鍵盤焦點。沿用 `hideMobileCta` 的頁面例外與現有 LINE 點擊處理。

## 5. 五個頁面的共用版型

內容仍由 `src/data/seoContentPages.js` 提供，使用同一個 `SeoContentPage.vue`，以現有 `page.type` 區分服務與疾病指南，避免複製五份頁面。

閱讀順序：

1. 返回首頁連結、頁面類別、完整標題、摘要、現有圖片與圖說。
2. 保留現有服務入口：電話洽詢與專業團隊連結；本批不變更目的地或醫療建議。
3. 現有重點資訊改為淺色、細線分隔的摘要列；手機依序排列。
4. 主要內文以章節編號、宋體小標與清楚段距呈現，保留全部段落。
5. FAQ 維持原生 `details`／`summary`，鍵盤可操作，完整答案保留在頁面中。
6. 延伸閱讀、參考來源與既有聯絡頁尾。

服務頁使用文字／圖片雙欄開場；疾病指南給較長標題更寬的文字欄與閱讀感。手機均為文字在前、圖片在後，文意與 DOM 順序一致。

桌面在內文旁放頁內章節目錄與既有延伸閱讀；目錄根據實際章節產生穩定的本頁錨點。手機目錄放在正文前，側欄延伸閱讀放在正文後，不固定遮擋閱讀。

保留照片／插畫原本用途與比例，醫療圖解不可裁掉標籤。每張圖片預留尺寸，首屏主圖優先載入，其餘延遲載入。

不啟用現有註解關閉的專業審閱文字、不新增審閱宣稱或醫療資歷。清除其留下的空白視覺欄位，但資料中的審閱者與結構化資訊不擅自修改。

## 6. 程式與資料邊界

- `App.vue`：維持首頁不重複顯示外層導覽／頁尾的行為；為公開內頁套用新版外框，保留管理與遊戲頁舊版例外。
- `Navbar.vue`、`Footer.vue`：在既有元件加入明確的新版變體，保持原有連結、聯絡處理與舊版例外可用。
- 共用設計變數：建立小型品牌樣式檔，使用命名空間／容器作用域；不新增全站的 `h1`、`a`、`.container` 或 `.site-footer` 覆寫。
- `SeoContentPage.vue`：負責本批五個頁面的版面、類別差異、目錄與 FAQ 呈現，不複製醫療資料。
- `src/data/seoContentPages.js`、`src/siteContact.js`：維持資料來源與內容；不另建第二份聯絡／醫療資料。
- 沿用現有 Vue、Bootstrap Icons、路由與 SEO 管線；不換框架、不新增外部字型請求或套件。
- 首頁元件與首頁 CSS 不因本批改版改寫；瀏覽首頁與分頁往返時，兩者樣式不能相互污染。

無對應頁面資料時提供簡短的「找不到頁面」內容與返回首頁連結，避免空白主內容；不建立新網址或改寫既有導向規則。

## 7. SEO、可及性與失敗處理

- 所有既有 canonical、標題、描述、結構化資料、sitemap 與內部連結保持一致。
- 維持既有靜態 HTML 內容輸出，搜尋用初始頁面仍包含全部章節、FAQ、來源與延伸連結；不只依靠 JavaScript 載入醫療內容。
- 本批不擴建全站預渲染系統；既有首頁完整靜態渲染與其他頁面的內容式靜態輸出皆保留。
- 每頁只有一個主要 H1、主要內容區、網站導覽與頁尾；標題層級連續。
- 文字對比至少 4.5:1，操作目標至少 44×44px；focus 樣式明顯，不能被固定工具列遮住。
- 動畫只用輕微的透明度／位移回饋，支援 `prefers-reduced-motion`；內容不依賴動畫才能顯示。
- 缺少選填圖說或內容欄位時不留空卡片；來源連結與圖片失敗時不新增虛構替代內容。

## 8. 驗收與交付

實作後須：

- 驗證五條路由均完整顯示既有標題、內文、FAQ、圖片及來源，服務／指南版型差異正確。
- 驗證手機選單開關、Escape、換頁關閉、頁內目錄與首頁錨點；確認電話、LINE、地圖與班表目的地未失效。
- 以 375、768、1024、1440px 寬度檢查換行、圖片、留白及固定工具列，不出現非必要水平捲動。
- 抽查尚未改內文的文章、獸醫師、產品與班表頁，確認新外框不遮擋原頁面內容；管理與遊戲頁保持原樣。
- 檢查首頁仍有八位獸醫師、原圖片與小寵物互動，且導覽與頁尾不重複。
- 執行 `npm run verify`，檢查正式建置、本批渲染與互動測試，以及既有 SEO 測試／檢核。
- 交付本機預覽連結、桌面／手機驗收摘要與實際變更範圍。未獲部署指示前，不推送會觸發正式部署的分支。
