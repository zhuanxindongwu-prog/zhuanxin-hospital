# LikeWater 檢驗報告建置中狀態設計

## 目標

暫時停止顯示 LikeWater 頁面中的六個外部檢驗報告連結，同時保留「檢驗報告」區塊與首頁導覽入口，讓訪客清楚知道內容正在整理。

## 呈現方式

- 保留 `Safety Reports` 與「檢驗報告」標題。
- 原六張報告卡改成單一置中的「檢驗報告建置中…」提示。
- 提示採用現有 LikeWater 頁面的白色卡片、藍色圖示與低彩度文字，不新增新的視覺語言。
- 保留 Hero 區的「檢驗報告」按鈕，並繼續連到 `#reports`。
- 不顯示或輸出既有 Google Drive 報告連結。

## 驗證

- 原始碼檢查必須確認建置中提示與 `#reports` 錨點存在。
- 原始碼不得再包含報告迴圈、報告陣列或 Google Drive 報告連結。
- Vite production build 必須成功。
- 瀏覽器確認區塊可見、錨點可達且沒有 console error。
