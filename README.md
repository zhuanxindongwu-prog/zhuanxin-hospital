# 專心動物醫院官網

專心動物醫院 CardioSpecial 官方網站。正式網址：

<https://cardiospecialvh.tw>

## 開發指令

```bash
npm install
npm run dev
npm run build
node scripts/seo-audit.mjs
```

`npm run build` 會先執行 Vite build，再產生靜態 SEO HTML、sitemap 與 robots。
