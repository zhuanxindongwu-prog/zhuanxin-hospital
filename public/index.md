01心臟超音波檢查Echocardiography

透過影像，看懂每一次心跳。評估心臟結構、瓣膜狀態、心房心室大小與心臟功能，為後續治療提供依據。

二尖瓣膜疾病 / 心肌病變 / 先天性心臟病 / 肺高壓評估

[了解更多](https://cardiospecialvh.tw/services/echocardiography)

02心律不整診斷Heart rhythm assessment

透過心電圖與 Holter 監測，判讀心跳過快、過慢或不規則，協助評估昏厥原因與用藥方向。

ECG 心電圖 / Holter 監測 / 昏厥評估

[了解更多](https://cardiospecialvh.tw/services/veterinary-cardiology)

03心臟病治療與追蹤Long-term cardiac care

依疾病分期與臨床狀態，規劃個別化用藥與回診追蹤，陪伴毛孩與家長面對每個照護階段。

MMVD 分期 / 心衰竭管理 / 居家呼吸監測

[了解更多](https://cardiospecialvh.tw/topics/mmvd)

04術前心臟風險評估Pre-anesthetic assessment

協助麻醉與手術前了解心臟風險，為高齡、心雜音或慢性病毛孩提供檢查與評估建議。

麻醉風險評估 / 高齡犬貓 / 腫瘤手術前評估

[了解更多](https://cardiospecialvh.tw/services/veterinary-cardiology)

05貓咪心臟疾病評估Feline cardiology

貓咪心臟疾病的症狀常不明顯，透過專科檢查，評估心肌病變、心雜音與相關風險。

HCM 評估 / 呼吸急促 / 血栓風險

[了解更多](https://cardiospecialvh.tw/services/veterinary-cardiology)
